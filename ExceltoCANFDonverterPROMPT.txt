Excel to CAN FD DBC 변환 프로그램-완전한 개발 명세서 (최종본)
작성일: 2024
버전: 2.0 (최종 완성)
■ 프로젝트 개요
Excel 파일(Signals 시트만 사용)에서 CAN FD DBC 파일을 자동 생성하는 Python 프로그램
- 입력 파일: CAN_FD_DBC_Data.xlsx 
- 출력 파일: CAN_FD_DBC_Data.dbc (Excel 파일명과 동일, 확장자만 .dbc) 
- 사용 시트: Signals 시트만 (Messages, ECUs 시트 불필요) 
- 데이터 읽기: 컬럼 인덱스(위치) 기반 
- 헤더 텍스트 자유 변경 가능 
- 모드: CAN FD (USE_CANFD = True)

■ Excel 컬럼 매핑 ( 완전판)
인덱스 기준: A=0, B=1, C=2, , Z=25, AA=26, AB=27, . AX=49..... BX=75
[메시지 기본 정보] B열(1): Send 제어기 (Sender ECU) -예: AAA, BBB, CCO 
C열(2): Source Address (Node ID) - 예: 0xAA, OxBB (16진수) 
F열(5): Message Name -예: EngineStatus, PowerStatus 
G열(6): Message ID (HEX) -예: 0x100, 0x18FFDOEE 
H열(7): Frame Type - 예: CAN FD Standard, CAN FD Extended 
|열(8): Data Length (DLC)-8, 16, 32, 64 바이트

[메시지 타이밍 속성] 
J열(9): Cycle Time (ms)-0~200000지원, 0도 유효한 값! 
K열(10): GenMsqCycleTimeFast (ms) 
M열(12): GenMsgStartDelayTime (ms) 
Z열(25): Send Type - Cyclic / NoMsgSendType

[메시지 전송 설정] 
BV열(73): GenMsaNrOfRepetition - 정수값 (0~100 
BW열(74): GenMsgILSupport -Yes / No

(메시지 네트워크 관리] 
BX열(75): NmMessage - Yes / No

[메시지 진단]
BM열(64): DiagRequest - Yes /No 
BN (65): DiagResponse - Yes/ No

[신호 정보] 
N열(13): Signal Name 
P열(15): Description 
O열(16): Receiver ECU 
S열(18): Bit Length 
U열(20): Start Bit 
V열(21): Byte Order (Intel / Motorola 
AB열(27): GenSigSendType 
- NotUsed - OnWrite 
- OnWriteWithRepetition 
- OnChange OnChangeWithRepetition 
- IfActive - IfActiveWithRepetition 
- NoSigSendType 
AO열(40): Value Type / Sign (Signed / Unsigned 
AP열(41): Initial Value (16진수 0x0도 지원, 자동 변환) 
AS열(44): Factor (Scale) 
AT열(45): Offset 
AU열(46): Min Value 
AV열(47): Max Value 
AX열(49): Unit

■중요 규칙 (반드시 준수!)
★ VFrameformat는 반드시 14/15 사용 (8/9 아님! 
- 14 = StandardCAN FD 
- 15 = ExtendedCAN FD 
- ENUM 정의: 총 16개 항목 (인덱스 0-15)       
★ENUM 속성은 인덱스(숫자) 사용 (문자열 아님!) 
- GenMsaSendType: 0="Cyclic", 1="NoMsgSendType" 
- VFrameFormat: 14="StandardCAN FD", 15="ExtendedCAN FD' 
- GenSigSendType: 0~7 (8개 옵션) 
- Yes/No 속성: 1="Yes", 0="No"

- 헤더를 한글, 영문, 어떻게 변경해도 작동

■ 문제 해결 가이드
[메시지가 1개만 생성됨]
 → B열(Send 제어기) 확인 (A열 아님!)
 → Message ID (HEX)가 각 행마다 다른 값인지 확인

[VFrameFormat 범위 초과 에러]
 → ENUM 정의가 0-15 (16개)인지 확인 
 → 14, 15 사용 확인

[Tx Method가 <n.a>] 
→ ENUM 인덱스(0, 1) 사용 확인
→ 문자열("Cyclic") 사용하지 말 것

[Cycle Time 이 잘못됨1]
 → 0 값 처리: if cvcle time is None 사용 
 → if not cycle_time: (X)

[ECU Address가 0x0]
 → C열 값 확인
 → 16진수 → 10진수 변환 확인

[Initial Value syntax 
→ 16진수 문자열(0x0) →10진수(0) 변환 확인

[No*와 No 차이]
 → No* = 기본값과 동일 
 → No =명시적 설정
 → 기본값과 같으면 BA_ 라인 생략

 - GenMsgCycleTime: INT 0-200000 (J열) 
 - GenMsgCycleTimeFast: INT 0-200000 (K열, 값 있을 때만) 
 - GenMsgStartDelayTime: INT 0-200000 (M열, 값 있을 때만)

 - GenMsgNrOfRepetition: INT 0-100 (BV열, 0 아닐 때만)

[메시지 속성 - Net Management]

[메시지 속성 - Diagnostics]
 - DiagRequest: ENUM 0-1 (BM열, 기본=No, Yes일 때만 출력)
